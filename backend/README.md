# Бэкенд — прокси к Claude API

Маленький сервер на Express. Единственная задача: принимать запросы приложения и
пересылать их в Anthropic, подставляя секретный API-ключ. Так ключ хранится тут,
а не в телефоне.

## Запуск
```
npm install
cp .env.example .env      # затем впишите ANTHROPIC_API_KEY в .env
npm start
```

## Эндпоинты
- `GET /health` — проверка, что сервер жив, и какая модель используется.
- `POST /api/chat` — тело `{ system?: string, messages: [{role, content}] }`,
  ответ `{ text }`.

## Модель
По умолчанию `claude-sonnet-5` (актуальный дефолт на июль 2026). Меняется в `.env`
переменной `CLAUDE_MODEL`. Проверить текущие модели: https://docs.claude.com/en/api

## Для продакшена
- Ограничьте CORS вашим доменом (сейчас открыт для всех — удобно для разработки).
- Добавьте аутентификацию (чтобы к прокси не мог обращаться кто угодно).
- Вынесите на хостинг (Render, Railway, Fly.io, свой VPS) и используйте HTTPS.
