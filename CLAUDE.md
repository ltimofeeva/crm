# Контекст для Claude Code

Это стартовый проект мобильного приложения **CRM для частного психолога** на
Expo (React Native). Он вырос из веб-прототипа (см. `reference/prototype-web.jsx`)
и уже запускается. Твоя роль — продолжать разработку по запросам владелицы,
которая НЕ программист. Объясняй шаги простым языком.

## Что уже есть
- Навигация: 5 вкладок (Сегодня, Клиенты, Контент, Аналитика, Финансы) + модальный
  экран ИИ-чата. Файл `App.js`.
- Экраны в `src/screens/`.
- Данные: локальное хранилище клиентов в `src/storage/store.js` (AsyncStorage).
  Приложение стартует пустым (демо-данных нет); клиенты добавляются на экране
  «Клиенты» (addClient), заметки — в карточке клиента (addSessionNote).
- ИИ: клиент `src/api/ai.js` ходит НЕ напрямую в Anthropic, а в бэкенд
  `backend/server.js` (прокси, хранит API-ключ). Три сценария: чат-ассистент,
  бизнес-анализ (план x2), пошаговый анализ клиента (структурный JSON).
- Подписка: RevenueCat (`react-native-purchases`). Обёртка `src/api/purchases.js`,
  статус — `src/context/SubscriptionContext.js` (хук `useSubscription`), экран
  `src/screens/PaywallScreen.js`. ИИ-функции закрыты правом (entitlement) `pro`.
  Если ключи RevenueCat в `app.json → extra` пустые или запуск в Expo Go —
  режим разработки, ничего не блокируется.
- Сборка: EAS Build (`eas.json`), профили development / preview (APK) / production.
  Инструкции для владелицы — в README, части B–D.

## Приоритеты доработки (по убыванию важности)
1. **Безопасность данных** (см. `SECURITY.md`). Сейчас заметки о клиентах хранятся
   в открытом виде на устройстве. Нужно: аутентификация входа (PIN/биометрия через
   expo-local-authentication), шифрование данных на устройстве (expo-secure-store для
   ключа + шифрованная БД, например через op-sqlite/SQLCipher), экран согласия клиента.
2. **Реальный бэкенд с БД** вместо демо-данных: хранить клиентов/заметки на сервере
   с аутентификацией пользователя (не только на телефоне), шифрование в покое.
3. **Живой календарь и запись** (сейчас данные календаря в прототипе, в приложение
   вынесена только лента «Сегодня»). Портировать недельный экран из прототипа.
4. **Стриминг ответов ИИ** (сейчас ждём полный ответ). В `backend/server.js` включить
   streaming, в приложении — постепенный вывод.
5. **Шрифты и иконки**: подключить кастомный serif через expo-font и набор иконок
   (например @expo/vector-icons) вместо текстовых символов во вкладках.

## Как проверять
- Бэкенд: `cd backend && npm i && cp .env.example .env` (вписать ключ) `&& npm start`.
- Приложение: `npm i && npx expo start`, открыть в Expo Go на телефоне.
- Адрес бэкенда для телефона задаётся в `app.json → extra.backendUrl` (см. README, Шаг 5).

## Стиль кода
- Палитра и токены — только из `src/theme.js`.
- Весь доступ к данным клиентов — через `src/storage/store.js` (чтобы замена на
  шифрованное хранилище была в одном месте).
- Все обращения к ИИ — через `src/api/ai.js` → бэкенд. Никогда не клади API-ключ в приложение.
